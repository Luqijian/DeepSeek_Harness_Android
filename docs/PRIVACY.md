# 隐私政策

Harness Android 是一个本地优先的开发者工具。

- **本地处理**：Linux 运行时、会话记录与工作区文件全部保存在设备应用私有目录；除你配置的模型服务外，应用不会上传任何数据。本应用自身没有遥测、没有统计 SDK、没有账号系统。
- **模型请求**：你在会话中发送的内容（可能包含工作区文件内容）会通过 HTTPS 直接发送给你在 Harness 设置中配置的模型服务商（如 DeepSeek API）。请自行确认所选服务商的数据政策，避免在对话中包含敏感信息。
- **存储权限**：本应用请求“所有文件访问权限”仅用于把你选择的文件夹作为工作区直接读写；应用不会扫描或读取你未打开的目录。
- **日志**：引擎日志仅保存在应用私有目录，可通过“设置 → 分享日志”由你主动分享。
- **卸载**：卸载应用会删除全部本地数据（运行时、会话、日志）。工作区中 bind 的原始文件夹不受影响。
